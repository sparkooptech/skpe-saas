# Hub de Planejamento Estratégico e Metodologia do SK-PE

## Objetivo

Organizar a rota principal de leitura metodológica do SK-PE sem transformar este hub em documento mestre e sem colapsar capacidade de negócio, módulo especialista e documentação de implementação em um único bloco indistinto.

## Definições canônicas

### Planejamento Estratégico

`Planejamento Estratégico` é a capacidade e o espaço temático cujo objetivo é:

> Constrói planos estratégicos realistas e executivos.

### SK-PE

`SK-PE — Especialista em Planejamento Estratégico` é o módulo especialista da Plataforma SPARKs com o papel de:

> Gerente Metodológico do Projeto de Planejamento Estratégico.

O SK-PE:

- estrutura;
- revisa;
- desdobra;
- audita;
- consolida planejamento estratégico institucional;
- preserva rastreabilidade;
- garante coerência metodológica;
- reforça executabilidade;
- reforça governança;
- orienta a decisão;
- seleciona a skill ou fonte canônica adequada;
- preserva o que já foi validado;
- elimina duplicidades;
- resolve contradições explicitamente;
- mantém uma única fonte canônica por conceito.

## Fronteira semântica

Pertence a este espaço:

- arquitetura metodológica da Formulação Estratégica;
- requisitos canônicos do ciclo FE;
- contratos que operacionalizam a experiência metodológica do SK-PE;
- definições canônicas de Planejamento Estratégico e do papel do SK-PE.

Não pertence a este espaço:

- relatórios históricos de auditoria;
- regras transversais de execução agentic que já vivem no guardrail;
- contratos arquiteturais da Plataforma que pertencem ao hub de arquitetura transversal.

## Progressive Disclosure

- Use este hub quando a tarefa exigir compreender Planejamento Estratégico como capacidade e SK-PE como módulo especialista.
- Use `REQ-SKPE-FE-001` para a cadeia metodológica central da Formulação Estratégica.
- Use os requisitos FE especializados para regras de governança, identidade e operacionalização.
- Use o contrato do Painel Principal quando a navegação operacional depender de preferência, contexto e elegibilidade de dashboards.
- Use a especificação de portabilidade quando a tarefa envolver exportação, importação assistida, planilha, HTML, JSON ou ZIP como canais portáteis do Planejamento Estratégico.
