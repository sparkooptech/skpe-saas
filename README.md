# SK-PE SaaS

Sistema de Gestão da Jornada Estratégica.

## Objetivo

Transformar os artefatos canônicos do SK-PE em uma plataforma SaaS para planejamento, execução, monitoramento, governança e comunicação estratégica.

## Estado atual

- Estrutura inicial do repositório criada
- Git configurado
- Docker Desktop validado
- Supabase local ainda não inicializado
- Aplicação web ainda não inicializada
